# Image Assets — Kopano B&B

Drop your photos into this folder with the exact filenames below.

| Filename | Content | Used In |
|---|---|---|
| `logo.png` | Transparent Kopano B&B logo (brown/gold, transparent background) | Nav, Hero, Footer |
| `hero.jpg` | Pool/garden panoramic shot — the most dramatic photo | Hero section full-viewport background |
| `pool.jpg` | Pool photo (can be same as hero or a second angle) | Parallax break section |
| `exterior.jpg` | Exterior / property front photo | About section |
| `room-standard.jpg` | A standard bedroom photo | Standard Room card |
| `room-deluxe.jpg` | A deluxe bedroom photo | Deluxe Room card |
| `room-family.jpg` | Family suite / larger room photo | Family Suite card |
| `room-executive.jpg` | Best bedroom / suite photo | Executive Suite card |
| `gallery-1.jpg` | Pool or aerial shot (displays 2× wide) | Gallery grid |
| `gallery-2.jpg` | Bedroom interior | Gallery grid |
| `gallery-3.jpg` | Breakfast or dining | Gallery grid |
| `gallery-4.jpg` | Lounge or communal area | Gallery grid |
| `gallery-5.jpg` | Bathroom or spa detail | Gallery grid |
| `gallery-6.jpg` | Garden or outdoor space (displays 2× wide) | Gallery grid |

## Tips
- Use JPG for photos (compress to ~300–600 KB each for fast loading)
- Recommended minimum size: 1200×900px for room cards, 1920×1080px for hero
- The logo MUST be PNG with a transparent background
- If you only have 3 photos right now, duplicate them across slots — the site still looks great
